  265x192

  根据检查结果，目前给VLM送进去的图片情况如下：
  图片数量：6张
  1. 1张全局拼接图 (global_collage.png)
    - 分辨率：2040 x 680
    - 包含3个全局视角的拼接
  2. 5张候选对象拼接图 (candidate collages)
    - 10_collage.png: 4353 x 720
    - 2_collage.png: 3298 x 720
    - 31_collage.png: 2824 x 720
    - 34_collage.png: 3209 x 720
    - 3_collage.png: 3667 x 72
  分辨率特点：
  - 全局图：固定高度680像素，宽度2040（3个视角横向拼接，每个约680x680）
*  - 候选图：固定高度720像素，宽度根据每个候选对象的多视角图像数量动态变化（2824-4353像素）
  - 所有图片都是横向拼接的collage格式，这意味着VLM需要处理的总分辨率相当大，尤其是候选对象图片，最宽的达到了4353像素。这可能会对VLM的处理效率和token消耗产生影响。

 用法一：单场景汇总

  python experiments/ablation/summarize_scene.py \<scene_root>
  <exp_dir> <scene_name>

  参数说明：
  - scene_root — 原始场景数据目录（含各任务子目录和 gt.json），如
  /media/yf/HIKSEMI/results_superpoints/scene0046_00
  - exp_dir — 某个实验的输出目录，如
  experiments/ablation/scannet/scene0046_00/exp_1_full
  - scene_name — 场景名，如 scene0046_00

  输出：
  - 打印 filtered/complete 两种 Acc@0.25 和 Acc@0.50
  - 在 exp_dir/summary.json 写入详细结果

  示例：
python experiments/ablation/summarize_scene.py \
  /media/yf/HIKSEMI/results_superpoints/scene0084_00 \
  experiments/ablation/scannet/scene0084_00/exp_2_no_global \
  scene0084_00

  ---
  用法二：跨场景批量汇总（aggregate）

  python experiments/ablation/summarize_scene.py \
      --aggregate \
      --ablation_dir <ablation_dir> \
      --exp <exp_id>

  参数说明：
  - --ablation_dir — 消融实验根目录，如 experiments/ablation/scannet
  - --exp — 实验名，默认 exp_1_full，可选 exp_2_no_global /
  exp_3_no_candidate / exp_4_simple_prompt

  前提： 各场景下的 <exp_id>/summary.json 必须已存在（先跑用法一）

  输出：
  - 打印跨场景汇总表（每行一个场景 + 总体指标）
  - 在 ablation_dir/aggregate_<exp_id>.json 写入结果

  示例：
  # 汇总 exp_1_full 所有场景
  python experiments/ablation/summarize_scene.py \
      --aggregate \
      --ablation_dir experiments/ablation/scannet \
      --exp exp_1_full

  # 汇总 exp_4_simple_prompt
  python experiments/ablation/summarize_scene.py \
      --aggregate \
      --ablation_dir experiments/ablation/scannet \
      --exp exp_4_simple_prompt

  ---
  典型工作流

  # 1. 先对每个场景每个 exp 跑单场景汇总
  for scene in scene0046_00 scene0077_00 ...; do
    python experiments/ablation/summarize_scene.py \
      /media/yf/HIKSEMI/results_superpoints/$scene \
      experiments/ablation/scannet/$scene/exp_1_full \
      $scene
  done

  # 2. 再跑 aggregate 得到跨场景总结果
python experiments/ablation/summarize_scene.py \
    --aggregate \
    --ablation_dir experiments/ablation/model \
    --exp exp_1_full
